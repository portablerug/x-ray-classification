# Source Code Layout (Planned)

This folder will contain project Python modules once implementation begins.

## Planned Package Areas

- `src/data/` - cloud access, metadata ingestion, cleaning utilities
- `src/features/` - preprocessing and image transforms
- `src/models/` - training and inference pipelines
- `src/evaluation/` - metrics, threshold analysis, comparison tools
- `src/utils/` - shared helper functions

Keep modules small, tested, and role-ownable.
